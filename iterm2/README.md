# iTerm2 Setup

## Font
- Font: **Hack Nerd Font** or **JetBrainsMono Nerd Font**
- Size: 14
- Install via: `brew install --cask font-hack-nerd-font` or `brew install --cask font-jetbrains-mono-nerd-font`
- The installer's font prompt only configures Ghostty — set the iTerm2 font by hand: Profiles > Text > Font

## Color Scheme
- Import **Rose Pine Moon** from: https://rosepinetheme.com/themes/
- Profiles > Colors > Color Presets > Import

## Settings
- Profiles > Terminal > Enable "Applications in terminal may access clipboard"
- Profiles > Keys > General > Left Option key: Esc+
